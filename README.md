# Basin & Bean Coffee Co. (Demo Site)

A mock website for a fictional Salt Lake City coffee shop. It's a sample of the kind of small-business site **Edward Palmquist Web Design** builds and sells. Made for IS 4496 (AI Product Management), Lab 12.

- Static HTML, CSS and JS with no build step
- Deployed on Vercel straight from this GitHub repo. Every push to `main` redeploys.

Files: `index.html`, `styles.css`, `script.js`.
